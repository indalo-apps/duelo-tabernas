# Duelo en Tabernas

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

Juego de reflejos para el móvil, ambientado en el desierto de Tabernas (Almería). Cuando aparece «¡DISPARA!», gana quien toque primero; si alguien toca antes de tiempo o se deja engañar por una distracción, pierde la ronda. Tiene tres modos: contra la máquina (una banda de rivales cada vez más rápidos), dos jugadores en el mismo móvil y una prueba de reflejos con tu tiempo medio.

Se publica con GitHub Pages: https://indalo-apps.github.io/duelo-tabernas/

Enlace para instalarla en el móvil: https://indalo-apps.github.io/duelo-tabernas/?instalar

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js), y añadir sus novedades en `NOVEDADES`. Los móviles que la tengan abierta se actualizan solos, sin cortar una partida a medias.

## Privacidad
No recoge ningún dato personal: sin cuentas, anuncios, compras, estadísticas ni rastreo. Los récords y ajustes se guardan solo en el móvil.
